# 팀 카톡 공지 — 주제 변경 제안

카카오톡은 마크다운을 렌더링하지 않으므로 아래 코드 블록 안의 내용을 그대로 복사해 붙이면 된다.
`[ ]`로 표시한 부분만 보내기 전에 채운다.

## 1. 짧은 버전 (단톡방 공지용)

```text
[AIRIS 주제 변경 제안]

주제를 이렇게 바꿔보면 어떨까 해서 공유합니다.

"체형·사용자 특성 기반 물리 시뮬레이션–AI 융합 사용자 맞춤형 에어게이트 최적화 시스템"

▶ 왜 바꾸려는지
지금 MVP는 맥락을 보고 LOW/MEDIUM/HIGH까지는 잘 정하는데,
그 결과가 누구한테나 똑같은 바람(fan 30/65/100%)으로 나갑니다.
115cm 어린이한테도 185cm 작업자한테도 같은 세기예요.
"같은 제어 수준을 사람 몸에 맞게 다르게 전달한다"를 추가하면
지금까지 만든 건 그대로 살리면서 주제가 훨씬 뾰족해집니다.

▶ 이미 만들어 둔 것 (기존 코드는 안 건드리고 위에 얹음)
1. 체형 추정: 포즈 관절점 → 키·어깨폭·머리/상체/하체 구역
2. 물리 시뮬레이션: 노즐 제트 감쇠 → 몸 표면 풍속 → 입자 제거율, 얼굴 풍속, 하중, 에너지
3. AI 대리모델: 시뮬레이터를 흉내 내는 신경망 (NumPy, R² 0.9998)
4. 최적화: 안전 한계 안에서 목표 제거율을 최소 에너지로
5. 대시보드 "맞춤 최적화" 모드 + 테스트 46개

▶ 결과 (페르소나 6명 × 제어 3단계 = 18건)
- 고정 제어는 18건 중 7건에서 취약 사용자 안전 한계 초과
- 표준 성인: 같은 제거율을 에너지 24% 적게
- 산모: 얼굴 풍속 9.6 → 6.0 m/s로 낮추고도 목표 충족, 에너지 47% 절감
- 어린이: 고정 제어는 덜 닦이는데 더 세게 밀림 → 맞춤은 한계 안에서 운전하고 관리자 호출

▶ 솔직한 한계
물리 모델은 CFD가 아니라 교과서 식으로 만든 간이 모델이고,
입자 탈리·안전 한계 상수는 아직 가정값입니다. 실험/CFD로 바꿔야 해요.

▶ 부탁
1) 주제 변경 찬반 의견 [ 날짜 ]까지 남겨주세요
2) 문서 한 번 봐주세요: docs/PERSONALIZED_OPTIMIZATION.md
3) 다음 회의 때 10분만 데모 보여드릴게요

브랜치/PR: [ PR 링크 ]
```

## 2. 자세한 버전 (의견 나온 뒤 역할 나눌 때)

```text
[AIRIS 맞춤형 에어게이트 — 상세 공유]

■ 한 줄 요약
기존: 맥락 → 위험도 → 고정 세기
추가: 맥락 → 위험도 → (이 사람 체형·특성) → 물리 시뮬레이션 + AI → 구역별 풍속·정지 시간

■ 추가된 파일
- airis/body_profile.py     체형·사용자 특성
- airis/gate_physics.py     물리 시뮬레이션
- airis/surrogate.py        AI 대리모델
- airis/gate_optimizer.py   최적화
- airis/personalization.py  제어 수준과 연결
- personalized_gate_app.py  단독 대시보드
- assets/user_profiles/     페르소나 6개 (표준 성인/어린이/고령/큰 체형/산모/휠체어)
- docs/PERSONALIZED_OPTIMIZATION.md  설계 문서

■ 실행 방법
python tools/run_personalization.py
streamlit run personalized_gate_app.py --server.port 8504
python -m unittest tests.test_body_profile tests.test_gate_physics tests.test_personalization

※ 단독 대시보드는 numpy + streamlit만 있으면 돕니다 (카메라 스택 불필요).
※ 기존 realtime_vision_app.py는 Python 3.14에서 av 패키지 설치가 실패합니다(제 환경에서 확인).
   카메라 모드까지 쓰려면 3.13 이하 가상환경을 권장해요.

■ 기존 파트와 이어지는 지점
- 비전/보행: 보행 분석 모드에서 키·어깨폭이 같이 추정돼서 맞춤 최적화로 넘어갑니다.
  보행속도는 통과 노출 시간에, 느린 보행은 안전 한계 선택에 쓰여요.
- 판단 로직: ML+Rule이 정한 제어 수준과 Actuation이 그대로 "목표"가 됩니다.
  혼잡도가 높으면 정지 시간을 줄이고 풍속으로 보상합니다.
- 환경: PM2.5/PM10 비율이 미세 입자 비율로 들어갑니다.
- 산모 연구: 산모는 카메라로 추정하지 않고 "시설 등록 민감 사용자"로만 받게 해뒀습니다.

■ 같이 정해야 할 것
1) 가정값 검증을 어디까지 할지 (챔버 실험 / CFD / 문헌값)
2) 안전 한계 숫자 (지금은 얼굴 풍속 10/8/6 m/s, 하중 체중의 2.0/1.2%)
3) 보행 데이터셋(Kuopio 등)으로 체형 추정 정확도 검증할지
4) 발표 스토리: "맥락 인지" 중심 유지 vs "개인 맞춤 최적화" 중심으로 이동

■ 나눠서 하면 좋을 일 (제안)
- 물리/CFD: 대표 체형 몇 개 OpenFOAM으로 돌려서 간이 모델과 비교
- 비전: 키·어깨폭 추정 오차 측정, 어린이 비율 보정
- 데이터/실험: 입자 탈리 곡선·안전 한계 문헌 조사 및 실험 설계
- 대시보드/발표: 고정 vs 맞춤 비교 데모 시나리오 정리

각자 맡고 싶은 부분 말해주세요!
```
